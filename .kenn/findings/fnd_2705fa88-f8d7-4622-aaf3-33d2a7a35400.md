Only prose reaches the embedding surface. Configuration values — identifiers, versions, type names, booleans — are not prose: embedding them costs vector storage and embed time on every run and dilutes recall for the conceptual queries vectors exist to serve. Achieve this by not feeding the prose surface, never by adding an exclusion list: the embed pass already skips symbols whose prose is empty (scan_rows), and such symbols stay findable through the lexical arms. Measured on a real repository, only 1.8% of XML elements carry any text at all.
