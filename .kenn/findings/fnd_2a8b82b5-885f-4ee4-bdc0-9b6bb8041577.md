Shell-safe pub_id rendering is per-language, NOT a universal string transform: each ingester owns its own escaping (SCIP backtick-unwrap vs markdown code-fence removal vs C# fn/generic grammar) — there is no correct universal backtick/hostile-char strip. The only shared piece is `shell_safe::is_safe`, the safe-alphabet contract.
