Atlas concept ids/filenames (okf.rs concept_id) are prefixed with the package's plurality language: `packages/<lang>__<flat-anchor>`. Without it a Rust crate `geo` and a C# project `Geo` write to the SAME file on a case-insensitive filesystem (mac/Windows) — `packages/geo.md` and `packages/Geo.md` are one file, so one concept clobbers the other while index.md still links to both. Because dep/domain links to OTHER anchors must reproduce the target concept's exact id, build_concepts computes an anchor->language map up front (plurality_language) and threads it into build_domains. Keep the language prefix — the concept id is atlas-internal, never a pub_id.
