Verify shipped indexer/CLI binaries on a MINIMAL/clean Linux (a bare ubuntu:noble container), not just a fat dev box or a CI compile — a green publish and a passing `cargo check --workspace` do NOT prove the binary STARTS. Two runtime libs are absent on a minimal Linux and abort the binary at load, both invisible on macOS and on a typical fat Linux: (1) libgomp.so.1 — ggml/llama.cpp OpenMP, pulled by kenn-embed llama-cpp-2 default `openmp` feature; disabled with default-features=false (ggml falls back to its own pthread pool). (2) libicu — .NET globalization for kenn-dotnet self-contained; dropped with <InvariantGlobalization>true</InvariantGlobalization> (an indexer uses ordinal string ops, needs no collation). Both surfaced only in a bare container during indexer-formulas task 6.1. After any release, run each shipped Linux binary `--version` in a minimal container to catch a missing shared lib before users do.
