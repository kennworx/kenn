Filter defaults are universal: include_tests and include_external default to false everywhere — the CLI global flags AND every MCP tool that filters (the graph-walk list_* tools were flipped from true), overridable per call. In find_usages, target RESOLUTION always includes tests+external so the pivot symbol is reachable by name (find_symbol_tiered(q, limit, true, true) in resolve_targets); the include_tests/include_external filters apply only to the TRAVERSAL (which referencing sites are returned), never to resolution. Same principle for any resolve-then-traverse tool.
