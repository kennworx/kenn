A test corpus for find_symbol needs at least two symbols with different names, or its name assertion is vacuous. find_symbol's 4th tier is n-gram fuzzy, so against a single-symbol corpus it returns that symbol for ANY query string — including one the corpus does not contain. A one-symbol fixture therefore passes a mutation that queries a nonexistent name, which is the exact false-guard shape CLAUDE.md section 9 warns about: the setup makes the assertion true for a reason production would not reproduce. Add a second, clearly-different name so the lookup has to discriminate, and assert match_kind ("exact" vs a fuzzy tier) so the test also pins WHICH tier answered.
