Markdown indexing inherits the excludes of every other language: if a directory is excluded for a code language, the markdown producer must skip it too. Enforced by markdown_with_inherited_excludes(config) in workflow.rs (markdown effective excludes = union of all languages excludes, unless [language.markdown].excludes is explicitly set). Do NOT widen WORKSPACE_HARDCODED_EXCLUDES to stop the atlas/markdown corpus from pulling in vendored dirs (e.g. Swift .build/index-build/checkouts/) — that changes global behavior for every language. The user re-includes a specific markdown dir by adding it to [language.markdown].excludes config, not by editing the hardcoded list.
