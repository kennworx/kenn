kenn's RustAnalyzer driver (driver/rust.rs discover_units) runs rust-analyzer once per cargo ROOT, discovering ALL of them by walking for every Cargo.toml — not just <workspace-root>/Cargo.toml. Classify each manifest: `[workspace]` is a root; `[package]` is a standalone root UNLESS it sits under a discovered workspace root (then it's a member, folded into that root's single run, since RA loads the whole crate graph from any member). This fixes the silent skip where a crate nested in a polyglot repo with NO root Cargo.toml produced zero rust symbols AND no report entry. run_unit points `rust-analyzer scip <unit.path>` at each root; the workspace-root crate keeps the bare `rust` slug, nested roots get a path-derived slug so scip outputs don't collide.
