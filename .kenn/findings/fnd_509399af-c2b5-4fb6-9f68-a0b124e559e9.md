Retrieval evals on the self-supervised gold set (query = documented symbol's first doc line): fused-hybrid deltas UNDERSTATE vector-arm effects because such queries are lexically biased — doc_fts/name arms already rank the target, and RRF dilutes the vector arm. Measured while shipping the query prompt: isolated vector arm +0.035 r@1, fused hybrid statistically zero (N=1000). Judge prompt/embedding changes on the isolated arm (prompt_ab); use the fused check (fused_ab) only as a no-regression gate, and expect real paraphrased-query gains to exceed the fused delta.
