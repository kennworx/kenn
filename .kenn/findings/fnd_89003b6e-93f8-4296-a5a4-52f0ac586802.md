Adding a new `Language` variant threads through more files than `language.rs` — miss one and you get a build error (exhaustive match) or silent wrong behavior. Full checklist (learned adding `Swift`):

1. `kenn-model/src/language.rs` — the enum variant + `prefix`/`extensions`/`project_files`/`db_name`/`from_prefix`/`from_db_name` arms AND the three exhaustive test arrays (`prefix_round_trip`/`extensions_cover_every_variant`/`project_files_have_no_leading_dot`).
2. `kenn-model/src/short_id.rs` — `partition()` (stable on-disk id partition). APPEND the next index; never renumber (existing ids encode it).
3. `kenn-indexer/src/transform/naming.rs` — `is_test_descriptor` (a JSONL-sidecar language with no descriptor convention goes in the `false` arm, like C#).
4. `kenn-indexer/src/transform/lang.rs` — `language_from_scip` + `language_from_path` arms; `transformer_for` returns `None` for a JSONL-path language (no SCIP `IdTransformer`, like C#).
5. `kenn-config/src/language/<lang>.rs` + the `LanguageConfig` field + crate `lib.rs` re-export + `config.rs` `validate()` (command-empty + excludes-glob loops) + the disjoint-`DEFAULT_EXCLUDES` test.
6. `kenn-indexer/src/driver/<lang>.rs` + `driver/mod.rs` registration, wired into BOTH `cmd_index.rs::build_driver` AND `workflow.rs::configure_runner` (see the two-builders directive), plus the `cmd_index.rs` no-languages guard.

A JSONL-sidecar language needs NO `kenn-model/id/<lang>.rs` and NO SCIP transformer — the consumer assembles `pub_id` as `prefix:key` generically (`transform_jsonl/stream.rs`).
