Per-language config in kenn-config is heterogeneous named fields (`CsharpConfig`/`RustConfig`/`PythonConfig`/`MarkdownConfig` differ in shape — `command`, `targets`, `roots`), NOT a `HashMap<Language, Config>`: a single map value type would force a fake union. A new language adds a named field on `LanguageConfig`. Use a `HashMap<Language, _>` ONLY for homogeneous per-language data — e.g. `Workspace.language_excludes: HashMap<Language, GlobSet>` (all values same type), which replaced four named `*_excludes` fields and removed the exhaustive match arms.
