kenn init --docker default images are DIGEST-PINNED manifest-list refs (ghcr.io/kennworx/<name>@sha256:...), held as the IMG_* consts in crates/kenn-cli/src/init/detect.rs and threaded onto LanguageSpec.default_image. Docker is a FALLBACK: init only containerizes a detected language whose local toolchain probe fails, and only with a runnable daemon. These digests go STALE whenever .github/workflows/images.yml republishes an image — refresh each with 'docker buildx imagetools inspect ghcr.io/kennworx/<name>:latest' and copy the top-level manifest-list digest (NOT a per-arch child). GHCR container-package visibility (private->public) has no REST API; it is web-UI only.
