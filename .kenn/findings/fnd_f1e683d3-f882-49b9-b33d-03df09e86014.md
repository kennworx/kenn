There are TWO live index-driver builders and a new sibling producer (markdown, css, …) must be wired into BOTH or it silently won't run on one path: `cmd_index.rs`'s inline runner builder (the `kenn index` CLI path, which calls `run_pipeline_with_progress` directly) AND `workflow.rs::configure_runner` (the `kenn mcp` reindex path, via `index_workspace`). PRE-EXISTING BUG found while adding css: `configure_runner` wires neither markdown nor css's sibling producers — only the SCIP/JSONL code drivers — so `kenn mcp` reindex appears to skip markdown. css was wired into both (`with_css`); markdown is still missing from `configure_runner`. When touching either builder, keep them in sync.
