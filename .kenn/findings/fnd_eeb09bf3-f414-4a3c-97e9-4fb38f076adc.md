The dist Release workflow (release.yml, generated by cargo-dist) and the sidecars workflow (.github/workflows/sidecars.yml) BOTH push Homebrew formulas to kennworx/homebrew-tap on the same v* tag. dist publish-homebrew-formula (kenn.rb) does NOT rebase-retry on a non-fast-forward; the sidecar publisher (publish-sidecar.sh step 4) does. So the sidecar publisher MUST wait for the dist Release run to finish before pushing (step 3.5: poll `gh run list --workflow Release --branch <tag>` until completed; needs `actions: read` permission) so dist push is uncontended. Without it the concurrent sidecar push makes dist lose the race and kenn.rb goes STALE at the previous version — v0.2.1 shipped fixed binaries but a v0.2.0 kenn.rb until the failed job was re-run, so brew served the broken build. Do not remove that wait, and do not add a second concurrent tap pusher without the same serialization.
