kenn-ts names a project by its package.json `name` — the npm-canonical source of truth — for in-workspace and external packages alike (indexers/kenn-ts/src/indexing/packages.ts). The directory basename is only a fallback when `name` is absent or the manifest is unreadable. A misleading `name` (a product name on a subproject, a stale starter-kit template) is the repo's OWN data, reported faithfully — the indexer must NOT rewrite names to directories to paper over it (that overstep silently mislabels honest names too). External deps keep their npm name; imports resolve by it. This name drives the atlas package/anchor title for TS. Supersedes the earlier directory-identity rule.
