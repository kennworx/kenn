The atlas (agent-facing OKF markdown map of the repo) is emitted BY kenn index itself, from the shared pipeline: compute_and_persist in kenn-indexer/src/aggregate.rs calls the atlas producer (src/atlas/producer.rs build_concepts + write_bundle) after the aggregate hook, keyed on resolve_anchors (package/crate anchors, NOT the packages table — Rust crates are absent from it). Both orchestration paths build an AtlasContext and pass it into run_pipeline_with_progress (cmd_index.rs for CLI, workflow.rs for MCP/reindex) so the bundle is produced ONCE in the shared path (see fnd_4c015b98). Never mock the atlas with a SQL/bash script — it must come from the real index. Reachable at the .kenn/atlas symlink pointing to the live OKF bundle. Symbol ranges are the full item extent (body_start_line..body_end_line via scan_def_lines_for_aggregation).
