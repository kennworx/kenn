Atlas concept ids/filenames (okf.rs concept_id): `packages/<lang>_<anchor>` — path separators flatten to `_` and runs collapse to a SINGLE `_` (collapse_underscores), never a doubled `__`, so a scoped `@atlas/strings` reads `packages/typescript_@atlas_strings`. The language prefix keeps a Rust `geo` and a C# `Geo` from colliding as filenames on a case-insensitive FS (mac/Windows). dep/domain links to OTHER anchors must reproduce the target's exact id, so build_concepts builds an anchor->language map up front (plurality_language) and threads it into build_domains; the component-label render splits the id on `_`. The concept id is atlas-internal, never a pub_id.
