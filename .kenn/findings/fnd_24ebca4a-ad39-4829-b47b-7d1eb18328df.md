Docker indexer-runtime caches split by shareability. Dependency SOURCES (CARGO_HOME registry, GOMODCACHE, NUGET_PACKAGES, pip/npm caches) go in a SHARED, cross-repo named Docker volume — a named volume, NOT a host bind mount, because bind-mounting a hot cache crosses the host<->VM filesystem boundary on macOS/Windows and the I/O penalty is severe. Build ARTIFACTS (cargo target/, Go build cache) must NEVER share a volume across repos: cargo locks target/, so a shared build cache deadlocks parallel indexer runs. Keep build artifacts ephemeral (in-container, dropped on --rm) or in a per-workspace volume behind a config flag. Also: named volumes are created root-owned, so a --user container cannot write a fresh one until kenn docker-volume-creates + chowns it to the invoking uid.
