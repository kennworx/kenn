Choose an atlas axis's input by the granularity of the question it answers, not by house style. Package and contract axes describe structure that exists at package granularity, so they project aggregate_nodes + aggregate_edges. An axis whose value is which SITE named something must project per-site edges instead: roll-up collapses a document's members into the document (measured 30410 XML elements to 483 aggregates), so an aggregated projection reports a file where the graph knows an element. Copying contracts.rs without checking this silently discards the attribution the axis exists to show.
