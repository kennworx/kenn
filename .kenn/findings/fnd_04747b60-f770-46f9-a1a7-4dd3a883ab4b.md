Recall-first "never drop a link" applies to NOTE links only — external URLs/emails and malformed wikilinks ARE dropped (no edge, no dangling stub), because they aren't notes. In kenn-indexer/src/markdown/links.rs: `is_external` (checked by resolve_link, which returns [] for it) flags a destination as non-note when it has a known URL scheme (EXTERNAL_SCHEMES, including the single-slash `https:/` typo), a generic `://`, OR a bare-email shape (`local@domain.tld`) — because pulldown-cmark surfaces email autolinks WITHOUT the `mailto:` prefix (that's added only by the HTML renderer we don't run), so `<mail@x.com>` arrives as a bare email and must be detected by shape, while a social-handle `@kepano` (no domain dot) is kept. `scan_wikilinks` also rejects a `[[…]]` whose inner spans a newline or contains `](`: a malformed `[[BUG]: title](url)` (a `[text](url)` typo) would otherwise let the `]]` search run across the file and swallow a garbage cross-line target.
