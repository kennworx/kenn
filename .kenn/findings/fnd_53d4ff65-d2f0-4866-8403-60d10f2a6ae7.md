kenn targets macOS, Linux, AND Windows. In the kenn-swift sidecar: (1) never use Darwin-only APIs without a fallback — mtime is st_mtimespec on Darwin, st_mtim on Glibc, Foundation attributesOfItem elsewhere (see Indexer.modificationDate); (2) never spawn via /usr/bin/env (absent on Windows) — resolve executables with Provisioning.findOnPath, which must skip directories (isExecutableFile is true for dirs via the search bit) and non-files like execvp does; (3) never canonicalize workspace roots with Foundation resolvingSymlinksInPath — it STRIPS /private on Darwin while the compiler records /private realpaths in index-store units, so prefix checks silently drop every unit; use canonicalWorkspaceRoot (POSIX realpath, Foundation only on Windows). Linux is verifiable in Docker; Windows is compile-by-construction until a CI job exists.
