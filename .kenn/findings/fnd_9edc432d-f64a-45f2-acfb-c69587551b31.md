The aggregate graph (kenn-indexer/src/aggregate.rs) includes markdown link edges so a markdown vault renders as a note-to-note graph: `KEPT_EDGE_KINDS` carries `Embeds` (weight 2) and `LinksTo` (weight 1) alongside the code edges — embed/transclusion is tighter coupling than a plain reference, mirroring calls>type-use. Note-LEVEL granularity comes from `is_aggregate_leaf` treating `Kind::Document` AND `Kind::Attachment` as roll-up leaves (like class-like): sections roll up into their owning document, but a document must NOT roll up into its directory module or every note would collapse to its folder and the note-to-note graph would be lost. `links_to_file` stays EXCLUDED from the aggregate — its target is a file row, not an aggregate symbol node.
