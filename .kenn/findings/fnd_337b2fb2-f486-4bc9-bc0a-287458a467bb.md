Verify an indexer docker image (docker/<name>) by INDEXING a real project through it, not by checking the tool answers `--help`. scip-python 0.6.6 answers `--help` with only python3 installed but dies at index time — it shells out to `pip list` for env eval and `git` for the project version — so the image shipped 'verified' yet indexed nothing. Fix: docker/scip-python/Dockerfile installs python3-pip + git, and `just docker-index-smoke` now indexes a real python package and asserts non-empty symbols + no 'failed'/'indexed 0 files' warning. Same §9 lesson as tests: exercise the real property, not a proxy.
