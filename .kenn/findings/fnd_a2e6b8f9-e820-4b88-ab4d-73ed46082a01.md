RESOLVED (was the deferred `get_source` declaration-only limitation): `kenn get source <id>` returns the WHOLE item, not just the declaration line. `get_source` (crates/kenn-mcp/src/tools/semantic.rs) prefers the STORED enclosing-item extent — `defs.body_start_line`/`body_end_line`, guarded by `body_end_line >= body_start_line && body_start_line >= 1` — and falls back to the name-token span only when no body extent was captured. The extent comes from what each producer already computes (SCIP `Occurrence.enclosing_range` for rust-analyzer >= Dec-2025, and the equivalent from the other producers), so nothing is parsed at query time. A symbol still showing one line means its producer emitted no enclosing range, not that the feature is missing.
