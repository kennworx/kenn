Read-path tools MUST NOT panic on index data. A symbol may carry several def rows including a spurious zero-range one (file_id != 0 but start_line == 0) some producers emit; pick the first VALID def (file_id != 0 && start_line >= 1) and return None if none — see first_def_location_string / defs_for_symbol / get_source. Do NOT use a debug_assert to 'surface a producer bug' from a read path: it crashes the CLI/MCP on real data. Filter defensively and record the producer bug as a finding instead.
