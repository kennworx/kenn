Markdown link extraction is hybrid (do not replace with comrak): `pulldown-cmark` (default-features=false, ~2 marginal crates) for CommonMark inline/reference links — it correctly excludes code spans/blocks + escapes and parses the destination grammar — plus a hand-rolled scanner for `[[wikilinks]]`/`![[transclusions]]`, which are NOT CommonMark, over the spans pulldown leaves as text/code. Do NOT switch to comrak: it pulls ~11 extra crates (a full GFM renderer we don't use) and still cannot parse wikilinks, so the custom scanner is needed either way.
