Markdown file-as-node and each heading are `SymbolRecord`s of kinds `Document`/`Section` (symbol id space), NOT `FileRecord`s. Why: `ShortId` is `[partition|counter]` with no file/symbol discriminator (short_id.rs), so within a partition file#1 and sym#1 collide; the code graph only disambiguates an edge target *by edge kind* (`contains` always targets the files table). Markdown `links_to`/`embeds` edges target arbitrary nodes, so markdown nodes must live in symbol space to be unambiguous targets. A markdown `FileRecord` (language=Markdown) is still emitted for the files table + content_hash, but link edges never target it.
