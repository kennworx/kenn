The atlas `domains` axis (second axis to `packages`) = cross-package flat-Louvain communities. build_domains in atlas/producer.rs keeps a community only when it (a) is flagged cross_anchor AND clears MIN_DOMAIN_SIZE in the flat record, and (b) STILL spans >=2 packages after restricting members to the domain-eligible set — non-container (no module/namespace/package), non-test, code + anchored nodes (the same exclusion the package central list uses, so a domain is never crowned by a `tests`/`mod` container). The hub (title + `domains/<slug>` id via okf::domain_id) is the highest-weighted-degree eligible member; central + spanned-packages rank by degree / member-count. Render via okf::render_domain (type: domain, no `resource`) + a Domains section in index.md. Determinism rides on louvain_flat being deterministic.
