Rust test-module layout: never leave a directory that exists ONLY to hold a tests.rs (the foo/core.rs + foo/core/tests.rs shape). Put a split-out test module in a SIBLING file foo/core_tests.rs, wired from core.rs as `#[cfg(test)] #[path = "core_tests.rs"] mod tests;` — declared in core.rs (NOT mod.rs) so the module stays a child of core and `use super::*` keeps reaching core's private items. Prefer the house-style inline `#[cfg(test)] mod tests { … }` (141 files use it; only the split-outs use `mod tests;`) when the combined file stays under the 30 KB `just large-files` gate — but rustfmt indents an inlined test body +4 bytes/line, so a file that fits by raw concatenation can still breach; these were split precisely because inlining breaches 30 KB.
