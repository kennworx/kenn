A round-trip test over a pair where BOTH sides derive from the same source guards NOTHING. `Kind::from_db_name` is `ALL.find(|k| k.db_name() == s)`, so `from_db_name(db_name(k)) == k` holds for ANY naming scheme: mutating the derive to kebab-case left both the round-trip test AND the uniqueness test green while every persisted `symbols.kind` value silently changed meaning and every existing snapshot became unreadable. Any string that is an ON-DISK FORMAT — `symbols.kind`, edge relation names, language db_names, node-id prefixes — MUST be pinned with LITERALS in a test (see `db_names_are_the_pinned_on_disk_vocabulary`), so a rename is a visible, deliberate edit rather than a side effect of a derive attribute, a serde rename_all, or a refactor. Uniqueness and round-trip tests are necessary and are not sufficient.
