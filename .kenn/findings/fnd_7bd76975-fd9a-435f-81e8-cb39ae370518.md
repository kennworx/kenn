Producer registration for indexing is DUPLICATED across two functions that must stay in sync: build_driver (crates/kenn-cli/src/cmd_index.rs, the CLI 'kenn index' path) and configure_runner (crates/kenn-indexer/src/workflow.rs, the workflow / MCP index_workspace path). They have drifted before — configure_runner was missing the with_markdown branch build_driver had, so MCP-triggered indexing silently skipped markdown even when enabled. Don't add or configure a producer on only one path; register it on both (or consolidate the two into one function — see openspec change index-producer-parity).
