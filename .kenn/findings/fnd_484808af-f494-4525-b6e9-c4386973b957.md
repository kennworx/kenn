Markdown link resolution is recall-first: NEVER drop a link. Downgrade through the ladder exact → drifted → fuzzy → ambiguous(keep-all) → dangling(external stub), name-anchored and qualifier-tolerant (filename/short-name survives rot; relative path or namespace may be stale → Drifted; multiple name matches → keep an edge to each, Ambiguous). Each edge carries its `LinkGrade`. md→code resolution is gated to in-repo roots only (external vaults resolve md↔md only) and runs against the code graph via a `CodeLookup` trait (store-backed post-code-barrier in Group 6).
