The atlas domains axis (build_domains in kenn-indexer/src/atlas/producer.rs) EARNS its spanned packages, it does not count them. Louvain clusters over the whole graph, so a raw community routinely lists packages joined only through a shared vendor type plus one-symbol stragglers. A package joins a domain's span only with at least MIN_PKG_MEMBERS members AND a first-party edge to another such package (supported_span); a cross-package domain needs at least two supported packages AND at least MIN_DOMAIN_LINKS distinct cross-package edges. A single-package community is kept only for a single-dominant repo (a monolithic library's intra-package cluster). The hub/title ranks by INTRA-domain degree (edges within the community), NEVER global degree: a ubiquitous value type (an enum referenced everywhere) has huge global degree but is peripheral to any one cluster, so global-degree ranking titled a domain by it and buried the type that actually organizes it. Supersedes the earlier count-based two-packages rule.
