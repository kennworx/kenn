Never teach a language indexer about shell-safety. The indexers — external tools (rust-analyzer, scip-go, scip-python) and our own sidecars (kenn-ts, kenn-dotnet, kenn-swift) alike — emit REAL, language-native code symbols and know nothing about shells. Shell-safe pub_id rendering is a Rust-ingestion concern owned solely by kenn_indexer::pubid::render, dispatched per-language on Language; it is never pushed down into a sidecar binary. If prettier/richer ids need more structure than the raw symbol carries, the sidecar emits a RICHER REAL symbol for the Rust renderer to interpret — it still never renders shell-safe itself.
