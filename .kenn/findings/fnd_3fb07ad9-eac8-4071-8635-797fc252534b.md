Code→stylesheet import edges (Phase 4 §11): pure helpers `css/usage.rs::extract_style_imports` + `is_stylesheet_import`; emission in `css/ingest.rs::emit_code_style_imports` inside the post-code barrier (`resolve_css_usage`). Recovers stylesheet imports that code indexers DROP — a `.css`/`.scss`/`.sass` import specifier has no code declaration, so e.g. kenn-ts's `moduleRef` returns 0 and the edge is never emitted. WHY the Rust barrier, not kenn-ts: wire edges are numeric `Ref`s siloed per producer — there is no cross-producer symbol table, and `transform_jsonl/stream.rs::on_edge` DROPS any edge whose target Ref is unknown (no stub), so kenn-ts cannot emit an edge to a CSS node minted by the Rust producer. The only cross-producer mechanism is the post-code store-lookup barrier where `resolve_css_usage` already runs (same pattern as markdown→code). Mechanism: per usage_sources file, scan `import`/`require`/`from` lines for quoted specifiers (keyword-gated to cut noise); classify as a stylesheet by MIME via `mime_guess::from_path` (text/css⇒Css, text/x-scss/text/x-sass⇒Sass; also keeps `.ts`=video/mp2t and `.json` OUT); only `.`-relative specifiers resolve (`internal::normalize_join`, made pub(crate)); target module = `module_id(lang, relpath)` → `reader.fetch_symbol(lang.prefix(), pub_id)`; source module = importing file's module via `list_inbound(file_id, "contains", 1)` (SymbolRow.id); emit module→module `EdgeKind::Imports{Explicit}`, deduped across files via a HashSet, skipping self + unresolved. Missing target → no edge (no dangling stub, per the usage no-stub rule). Reuses `EdgeKind::Imports` so `list_imports` stays uniform — a stylesheet's inbound importers may mix stylesheets and code, distinguished by source language. Gated on usage_sources + the post-code barrier (source is a code node, like uses_css_class); `import_edges` added to `CssUsageCounts`. OUT OF SCOPE: aliased/bare specifiers (`@/…`, `~pkg/…`) — path-mapping lives in the code indexer, which cannot carry the cross-producer edge. Overlaps the still-deferred 7.3 (CSS-Modules member binding), which shares the import scan.
