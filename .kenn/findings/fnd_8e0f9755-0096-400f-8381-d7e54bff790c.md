Markdown is a sibling producer to the SCIP path (it does NOT enter the SCIP `transform` chain, and is not a SCIP/JSONL driver). It owns its own discovery: `MarkdownConfig` (its own field on `LanguageConfig`) carries search globs (roots) + exclude globs as raw patterns; the markdown walker compiles and applies them itself at discovery time. A directory glob means recursive `<dir>/**/*.md`. Markdown does NOT route through `Workspace::is_excluded` — that is the code/SCIP-transform exclude path (code-only). External vault roots carry a label; in-repo roots default to label `workspace`.
