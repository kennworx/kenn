Empty-snapshot classification for agents (ConfigHint in kenn-mcp error.rs). When a snapshot has zero symbols, kenn classifies the cause into one of three kinds so the agent knows what to do: (1) no kenn.toml at the workspace root → `not-initialized` → suggest `kenn init`; (2) kenn.toml present but every [language.*].enabled is false → `config-disabled` → enable a language; (3) at least one language enabled but zero symbols produced → `configured-but-empty` → check excludes / indexer report. `ConfigHint::classify(config, symbol_count, config_present)` takes a `config_present` bool (does kenn.toml exist at source_root) to separate (1) from (2); ServerState::config_present() computes it from the live layout so a roots rebind is reflected. The hint is surfaced on BOTH the EMPTY_SNAPSHOT error (data tools) and get_workspace_overview's config_hint field. Keep all three branches when editing this path.
