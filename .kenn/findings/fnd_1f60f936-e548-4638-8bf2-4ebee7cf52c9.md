The gix facade crate pulls network plumbing (gix-protocol / gix-transport / gix-packetline / gix-refspec) as UNCONDITIONAL deps even with default-features=false — you cannot feature-gate them away; you only avoid the heavy HTTP clients (curl/reqwest) by NOT enabling the blocking-http-transport-* features. Minimal working feature set for kenn read-only git: ["status", "max-performance-safe", "sha1"] — sha1 is REQUIRED (object ids; omitting it fails gix-hash compile), status transitively pulls dirwalk/blob-diff/gix-status, max-performance-safe is the pure-Rust zlib backend (no C dep). Measured adoption cost (gix 0.85): +69 crates (351 to 420 in the graph) and +1.9 MiB on the release binary (15.8 to 17.7 MiB, after lto+strip DCE drops the unused network paths).
