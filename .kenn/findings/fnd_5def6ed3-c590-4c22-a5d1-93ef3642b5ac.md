kenn-dotnet flags a C# project as test code (all its symbols emit test=true) when it (a) references a test framework / the VS Test Platform (xunit/nunit/mstest/Microsoft.TestPlatform — which also covers every Microsoft.NET.Test.Sdk project, since those reference TestPlatform) OR (b) its assembly name matches a configured `[tests] assembly_regex` (repeatable regex, e.g. `Test$` for a repo whose test assemblies all end in Test). Both signals read the ALREADY-LOADED Roslyn project (project.MetadataReferences / project.AssemblyName) — do NOT re-evaluate via Microsoft.Build.Evaluation LoadProject just to read the IsTestProject MSBuild property: that is a full second SDK evaluation per project, and the reference check already catches IsTestProject-marked (Test.Sdk) projects for free. Detection runs in a race-free pre-pass (MarkTestProjects) before the parallel walk; FileTracker ORs the test-project path set into its per-file flag. Config flows [tests] assembly_regex -> the kenn-dotnet driver -> --test-assembly-regex.
