The detection table (SPECS in crates/kenn-cli/src/init/detect.rs) is the single source of truth for each language: markers, source globs, test globs, excludes, and the version probe. The probe derives from the config default command via probe_command: Some(|| <Lang>Config::default().command) so it never diverges from the index-run command, and the starter template ships [tests] paths empty so init seeds it from the table. Do not hardcode probe binaries or add per-language globs to starter_kenn.toml; extend the table instead.
