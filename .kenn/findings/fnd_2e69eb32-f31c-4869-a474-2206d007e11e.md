Build all six indexer images in ONE bake graph (docker/bake.hcl), never a six-way CI matrix. This SUPERSEDES the requirement that each language have 'a matrix entry in .github/workflows/images.yml' — the coverage rule stands (every code driver needs an image or a documented blocker), the matrix does not.

WHY: every image copies the same kenn-toolchain provisioning entrypoint. Six images x two platforms was TWELVE Rust compiles per publish, half of them under QEMU on an amd64 runner. Parallel matrix jobs CANNOT dedupe that — they are separate build graphs. buildx bake puts them in one graph, so 'entrypoint' is a shared target built once per platform and pulled in by each image via contexts = { entrypoint = "target:entrypoint" }. The workflow is now a single 'docker buildx bake -f docker/bake.hcl --push default' step with REGISTRY/TAG/PLATFORMS as env.

Also superseded: 'sidecar images must keep the language SDK in the FINAL image'. They must NOT — see the on-demand provisioning directive. kenn-dotnet is published self-contained so it carries its own net10 runtime and runs against whatever SDK major the workspace pinned, including an older one.

STILL TRUE and worth keeping: layer sharing between these images is ONE layer (the ubuntu:noble rootfs) — measured, 24 other layers each unique to a single image. Even the byte-identical 2.06MB entrypoint COPY does not dedupe, because its tar carries parent-directory state that differs under a differing apt layer. All six apt-install 'git ca-certificates'; go and rust each separately install 'gcc libc6-dev' (~180MB). An intermediate shared base target would dedupe both. Not yet done — it is an optimization, worth nothing to a single-image user and real for multi-language workspaces, the registry, and CI cache.

MEASURING image size: report the per-image 'docker images' figure. Do NOT sum that column — it counts the shared base once per image (3.27GB summed vs ~2.6GB actual). docker image inspect .Size and docker history disagree (compressed vs uncompressed under the containerd store); pin down which you are quoting before quoting it.
