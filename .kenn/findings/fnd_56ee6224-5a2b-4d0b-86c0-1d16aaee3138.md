Validate any cross-language graph feature against ONE REAL REPO PER LANGUAGE before designing on top of it. The atlas package/arrow view was designed entirely from this Rust workspace and looked sound; probing six real repos showed it worked on 3 of 6, and the three failures were upstream of anything the renderer could fix — Go collapsed 8 packages into 1 anchor (manifest anchoring), TypeScript's first-party cross-package edges were all classified external (build-output resolution), and only Python's single anchor turned out to be CORRECT. Both real defects were invisible from the Rust workspace, which has one manifest per crate and no build-output indirection. The probe that finds them is small: per repo, count distinct anchors, count distinct cross-anchor package pairs, and count distinct edge kinds among them; a language reporting 1 anchor or 0 arrows on a repo you know is multi-package is a defect, not an empty result. Keep the indexed repos in ./tmp so the comparison is repeatable.
