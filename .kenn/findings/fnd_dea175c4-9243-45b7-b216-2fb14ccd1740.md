Guards that SCAN SOURCE by filename or content (e.g. kenn-store/tests/layout_guard.rs, which rejects hardcoded store-path joins outside layout/) only fail at test-RUN time — `cargo clippy --all-targets` compiles test targets but does NOT run them, so it stays green while such a guard is actually broken. After relocating or renaming files, run the full suite (or `just crap-ci`), not just clippy. Concretely: renaming the split-out test files tests.rs -> <name>_tests.rs slipped past clippy and only surfaced in crap-ci, where layout_guard flagged the moved core_tests.rs fixtures until its exclusion learned the <name>_tests.rs naming.
