docker/bake.hcl must keep its build cache gated behind a CACHE variable (default empty), never hardcoded type=gha. `cache-to type=gha` is a HARD error without an Actions token, so a hardcoded gha cache makes the single local build command unrunnable. Local build (all six images into `docker images`): `docker buildx bake -f docker/bake.hcl --load` — empty CACHE means no external cache; the default group + --load loads the results. CI sets CACHE=gha (env in .github/workflows/images.yml) to restore the cross-run layer cache. Verify a built image is real by running its entrypoint (`docker run <img>` prints kenn-toolchain usage), never by trusting `docker image inspect` mid-build (it races the --load re-tag).
