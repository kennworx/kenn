A corpus/fallback Language with NO fixed extensions (Text; Markdown is also roots-driven) is the exception to the add-a-Language checklist: (a) it is NOT added to the extensions_cover_every_variant / project_files_have_no_leading_dot test arrays in language.rs — those assert non-empty, and such a language deliberately returns &[] for extensions()/project_files(); add a dedicated round-trip test asserting emptiness instead. (b) it is NOT added to language_from_path in transform/lang.rs — it is discovered by glob/producer, never inferred from a file extension. (c) it still needs the short_id partition (append the next index), the prefix/db_name/from_prefix/from_db_name arms, and the transformer_for None + is_test_descriptor false arms.
