The atlas package concept summarizes its files as a heading '## Files under <package-dir> - <total>' followed by one '- <dir> - <count>' line per directory (each file's parent dir relative to the package root, sorted count-desc then path) — NOT a truncated top-N file list (that silently under-reported and read like a member list). The heading total is the TRUE file count; no file is omitted. A component (single source dir) still lists its files individually. Central symbols render as '## Central symbols under <package-dir>' — bare, no parens, backticks, or trailing slash — with locations shortened relative to that dir. Carried on Concept as file_count + dir_counts; producer.rs dir_histogram builds the histogram, okf.rs render_concept renders it. Keep atlas section headings in this de-cluttered 'under <dir>' style.
